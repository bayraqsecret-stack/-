# PayFlow Pro 💳

Full demo payment system with QR, scanner and receipts.

## Features
- Kaspi / QIWI / Freedom UI (Demo)
- QR receipt generation
- QR code scanner
- Receipt storage (local)
- Mobile-first design
- GitHub Pages ready
- No backend

## Use case
Portfolio • Demo • Exhibition • Education

⚠️ Payments are simulated. No real money processed.
